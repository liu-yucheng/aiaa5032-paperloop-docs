    PaperLoop - v0.5.0

    PaperLoop API documentation

    PaperLoop is a DeepSeek Harness plugin. It reproduces the experimental setup of one paper and writes two critical reports. A forward pass runs six stages through isolated subagents. A backward pass runs the seventh stage.

    Start here

    • Commands: /paperloop forward and /paperloop backward. The shortcuts are /paperloop_forward and /paperloop_backward.
    • Tools: paperloop_forward, paperloop_backward, paperloop_status, paperloop_audit, and paperloop_config.
    • Stage order: runtime_setup, reproduction_code, reproduction_report, innovation_code, innovation_report, self_eval, and self_evolve.
    • Workspace: the current DeepSeek Harness session workspace. One paper uses the sub-workspace <workspace>/<paper_stem>/.
    • App data: ~/.dsh-aiaa5032-paperloop by default. The plugin settings page sets the directory and clears or resets it from the packaged default_app_data seed.
    • Stage time limits: one float in seconds for each stage. Stages 1 to 3 have 300 seconds, stages 4 and 5 have 240 seconds, stage 6 has 180 seconds, and stage 7 has 120 seconds. The plugin settings page sets or resets the seven limits. A setting value of 0 uses the value in configs_ro/v<N>/rsi.json.
    • Scale policy: Runtime and Coder run one minimal setup that finishes in 30 seconds or less. The main script accepts --minimal-scale (default), --reduced-scale (5 minutes or less), and --full-scale (no limit). A human user runs the last two flags after the session ends.
    • Pending directories: a successful forward pass writes the evaluation to <app_data>/evals/pending/<session>/ and the evolution plan to <app_data>/evolutions/pending/<session>/. A successful backward pass moves both directories to applied/.

    For AI agents

    Every AI agent that reads, edits, runs, or reviews this repository must follow three style guides:

    • natural_language_styles for documentation, prompts, commit messages, and code comments.
    • python_code_styles for Python code.
    • typescript_code_styles for TypeScript code, tests, and scripts.

    The repository root holds AGENTS.md with the binding instructions. CLAUDE.md points to the same file.

    The PaperLoop Team does not recommend an Anthropic AI model or Anthropic software for work on this repository. Prefer a model and a tool from another provider. This is a recommendation, not a technical restriction.
