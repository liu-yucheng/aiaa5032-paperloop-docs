Font regulation

This page states the font regulation for every web page in this repository. A human author and an AI agent follow the same regulation. The regulation uses three free families and no commercial family.

The rule

  1. R1. Use Noto Sans for every sans-serif face. The CSS stack is "Noto Sans", system-ui, sans-serif.
  2. R2. Use Noto Serif for every serif face. The CSS stack is "Noto Serif", serif.
  3. R3. Use Cascadia Mono for every monospace face. The CSS stack is "Cascadia Mono", ui-monospace, monospace.
  4. R4. Do not name a commercial font in a stylesheet, an SVG file, a script, or a document. A fallback entry counts as a name.
  5. R5. Do not add a font file to this repository. The three families are named, not bundled.
  6. R6. Follow the generic family after the named family. Use sans-serif for R1, serif for R2, and ui-monospace then monospace for R3. Do not add a second named family to a stack.

The three families

Face Family Licence Published by
Sans-serif Noto Sans SIL Open Font License 1.1 Google
Serif Noto Serif SIL Open Font License 1.1 Google
Monospace Cascadia Mono SIL Open Font License 1.1 Microsoft

The SIL Open Font License permits use, study, modification, and redistribution of the font. It permits a document that uses the font. It does not permit the sale of the font by itself. This repository ships no font file, so the licence applies to the reader installation only.

Where the rule applies

File What it holds
docs-src/docs.css The three custom properties --paperloop-font-sans, --paperloop-font-serif, and --paperloop-font-mono. Every hand-written page reads these properties.
docs-src/api-fonts.css The override for the TypeDoc theme. The theme stylesheet names commercial families. This file loads after the theme and replaces each stack. typedoc.json declares it in customCss.
docs-src/*.svg The two figures and the logo assets. A figure sets font-family="'Noto Sans', system-ui, sans-serif" on each text element.
client/index.js The style block of the plugin settings page. It sets the monospace stack on a path field.
docs/ The generated documentation. Do not edit this tree by hand. Run bash generate-docs.bash after a change to a source file.

Exceptions

  • The logo wordmark is an outline. The text PaperLoop in docs-src/logo-lockup.svg is a vector path made from Noto Sans Bold. The file contains no font reference, so the logo renders the same on a machine without the font. The mark itself is a path in every logo file.
  • The TypeDoc theme keeps its own stacks. docs/assets/style.css is generated output. It names several commercial families. docs-src/api-fonts.css loads after it, so the rendered page uses the three free families. Do not edit the generated stylesheet.
  • A missing family falls back to the generic family. A reader who lacks Noto Sans gets the system sans-serif face of the browser. The page stays readable, and the fallback names no commercial font.

How to check

Run each command at the repository root.

Check 1. The declared stacks.

grep -rhoE "font-family:[^;]*|font-family=\"[^\"]*\"" \
  docs-src client scripts src README.md typedoc.json \
  --exclude=fonts.html | sort -u

The command prints these four lines and no other line.

font-family: "Cascadia Mono", ui-monospace, monospace
font-family: var(--paperloop-font-mono)
font-family: var(--paperloop-font-sans)
font-family="'Noto Sans', system-ui, sans-serif"

Check 2. The three custom properties.

grep -hoE -- "--paperloop-font-(sans|serif|mono): *[^;]*" docs-src/docs.css

The command prints these three lines.

--paperloop-font-sans: "Noto Sans", system-ui, sans-serif
--paperloop-font-serif: "Noto Serif", serif
--paperloop-font-mono: "Cascadia Mono", ui-monospace, monospace

Check 3. No commercial family name.

grep -rniE "(segoe|sfmono|consolas|menlo|roboto|helvetica|arial|georgia|ubuntu|\bInter\b)" \
  docs-src client scripts src README.md typedoc.json \
  | grep -v "docs-src/fonts.html"

The command prints no line. This page holds the pattern itself, so the second filter drops this page from the result.

Check 4. The logo files hold no font reference.

grep -c font icon.svg docs-src/logo.svg docs-src/favicon.svg docs-src/logo-lockup.svg

Each line ends with :0.

A reader who adds a web page, a figure, or an icon applies R1 to R6 in the same change.

Agent policy. An AI agent that writes web content in this repository applies this regulation. A violation is a defect of the change, not a style preference.
